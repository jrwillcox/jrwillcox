### 🛠️ What I'm building

**[swu-engine](https://github.com/jrwillcox/swu-engine)**: a complete rules engine, computer
opponents and a web app for the *Star Wars: Unlimited* card game.

- **Every card in the game is playable**: all 2,636 of them, written as declarative data rather than one-off code
- **5,600+ automated tests**, including property-based tests that play whole randomised games and check the rules after every move
- **Bot opponents**: a tunable heuristic bot, plus an LLM-backed one (Claude) that falls back gracefully when it can't reach the API
- **Python + FastAPI** on the back end, **React + TypeScript** on the front end
- Built with a lot of help from **Claude Code**.
